# Network Scanner

A simple Python TCP port scanner created as a learning project for network security and Git.

## Features

- TCP port scanning
- Scanning multiple ports
- Default scanner configuration
- Basic logging
- Automated tests

## Project structure

```text
network-scanner/
├── scanner.py
├── config.py
├── logger.py
├── tests/
│   └── test_scanner.py
├── requirements.txt
├── pytest.ini
├── .gitignore
└── README.md


Requirements
Python 3.13+
pytest


Installation

Clone the repository:

git clone <repository-url>
cd network-scanner

Install dependencies:

python3 -m pip install -r requirements.txt
Usage

Run the scanner:

python3 scanner.py

Run tests:

pytest

This project is used to practice:

Python networking
